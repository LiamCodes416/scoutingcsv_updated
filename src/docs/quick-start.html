ScoutingAppRebuilt Quick Start Guide

Installation Guide

ScoutingAppRebuilt is only available to Android Devices that run 5.0 or higher. You will also need ADB installed on your system for the installation and usage of this app.

To get started, go to the releases page and download the latest APK:

https://github.com/GenshinAddict416/ScoutingAppRebuilt/releases


Plug in your android device using its charging cable. Ensure developer options are enabled. Approve your computer on the popup on the screen of the device.

You can install the APK using ADB with the following command on the computer with the APK downloaded:

adb install path/to/ScoutingAppRebuilt.apk

After installation, you can open the app on your device and start using it for scouting!

Getting Started

  1. Open the app on your android device.
  2. Then, open the ScoutingAppRebuilt Hub.
  3. Next, go to the "Settings" menu and input your FIRST API Key.
  4. Then, generate the QR codes for your event.
  5. Scan the QR codes with the android app and you should be ready to start scouting!

If you don't have a FIRST API Key, you can obtain one from the FIRST website.

For more detailed instructions on getting the key, please go to the "Help" page.
