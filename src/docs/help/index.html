FIRST API Key

If you don't have a FIRST API Key, you can obtain one from the FIRST website.

  1. Go to the link here.
  2. Fill out the form with your information.
  3. After submitting the form, you should receive an email with your API key.
  4. Copy the username and API key, and paste it into the "Settings" menu of the ScoutingAppRebuilt Hub.

Once you input the username and key and have hit the save settings button, the app will remember the username and key, as long as you are on the same device.
